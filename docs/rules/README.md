# Quy tắc và quy ước (Rules & Conventions)

Thư mục này tập hợp các quy ước phát triển của dự án MiniBanking.

## Danh mục

- [api-conventions.md](./api-conventions.md) - Quy ước trả về API, mẫu thông báo tiếng Việt.
- [entity-conventions.md](./entity-conventions.md) - Sử dụng lớp cơ sở `Entity`, các trường audit.
- [naming-conventions.md](./naming-conventions.md) - Quy tắc đặt tên trong dự án.

## Mục đích

Đảm bảo mã nguồn nhất quán, dễ đọc và dễ bảo trì cho toàn bộ team.
